# Library

A small in-browser reading tracker built with plain HTML, CSS, and JavaScript.

## What it does

- Add books with a title, author, page count, issue year, and read status
- Toggle each book between `Read` and `Unread`
- Remove books from the list
- Keep the add-book form in a modal dialog for a cleaner workflow

## Files

- `index.html` - page structure and modal form
- `style.css` - layout, color, card, and form styling
- `script.js` - book creation, state updates, and form handling

## How to use

1. Open `index.html` in a browser.
2. Click `Add Book`.
3. Fill out the form and submit it.
4. Use the status and remove buttons on each book card to update the list.

## Notes

- The app runs entirely in the browser.
- No build step or external dependencies are required.
